# Validation

Passed automated checks for blocked domains and subdomains, uppercase/trailing-dot hostnames, Google outbound redirects, YouTube blocking and LinkedIn exceptions, unrelated lookalike domains, and consistency between the domain list and network rules. Main-frame navigation is explicitly included in the blocking rules.

Chrome could not launch inside the build environment, so loading the extension, visual appearance, actual network enforcement, and live Google markup remain unverified. Follow the quick checks in README.md after installation. Google result filtering is best effort and may need updates as Google changes its markup.
